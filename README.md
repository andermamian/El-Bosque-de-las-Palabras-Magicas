# El Bosque de las Palabras Mágicas

Juego educativo de conciencia fonológica e iniciación a la lectoescritura para primer grado de primaria.

## Jugar

El juego se publica como sitio estático con GitHub Pages. Abre el enlace del repositorio y funciona en navegadores de PC y Android compatibles con pygbag/WebAssembly.

## Estructura

- `index.html`, `favicon.png`, `version.txt`: entrada y archivos públicos del build web.
- `assets/main.py`: código fuente original del juego.
- `assets/audio/`, `assets/imagenes/`: carpetas reservadas para recursos del juego.
- `build/web/`: copia del build generado.

La lógica original de `main.py` no fue modificada.
